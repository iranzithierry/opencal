**Opencal** is an opensource project that use real-time technology to initiate voice calls to users using your site.

The admin have access to see all users that are using his site and can choose one of them based on IP, Location and initiate call with him/her and the system notify the user that Developer is requesting for a call
then the user can reject or hang up


technology used:
 - Express
 - Socket.io
 - WebRTC


to get started 

```bun install``` or ```npm install```
```bun src/server.ts```
